# Contributing

Start with the [agent handoff](AGENTS.md) and [development workflow](docs/workflows.md). To report install or playback behavior, include the release, model, firmware, and the shortest steps to reproduce. See [troubleshooting](docs/troubleshooting.md) for details to redact.

For a pull request, explain what changes on screen, how you verified it, whether you ran on a physical TV, and any new artwork provenance. A small screenshot or screen recording helps for visual changes. Use a browser preview or crop out incidental personal details.

The gallery is focused on offline artwork playback. Keep launcher features and system-wide experiments in their own projects.
